# 企业知识库总结与分析

对知识库中的文档内容做结构化**总结**或**对比分析**，以表格形式输出；用户要求输出文档时写入本地文件。范围由用户指定：全库 / 某公司 / 指定文档 / 多公司对比。

## 执行流程

1. **确定范围**：先调用 `kb_list_docs` 查看文档列表（可按 `company_code` 过滤），确定总结/分析对象并记录目标 `doc_id`。
   - 多公司/多年份对比时：分别列出各家公司的文档，收集全部目标 `doc_id`。
2. **分主题检索**：将目标拆分为主题（如：财务数据、业务结构、风险事项、战略规划），对每个主题调用 `rag_search` 检索；**务必传入 `kb_list_docs` 得到的 `doc_ids` 限定范围**，确保内容来自目标文档。
   - 对比场景：对**每家公司（或每个年度）**分别按同一组主题检索，保证指标口径一致、可对比。
3. **汇总输出**：
   - 单文档总结：表格汇总各主题要点。
   - 多公司/多年份对比：用**对比表格**呈现（行 = 指标，列 = 公司 / 年度），并给出差异与亮点结论。
4. **输出文档**（用户要求"输出/生成文档"时）：将完整分析结果写入本地文件 `workspace/reports/<描述性名称>.md`（用 `file_write` 工具写入，路径相对本地 workspace；目录不存在先 `mkdir`），并在回复中告知文件路径与内容摘要。

## 输出要求（严格遵守）

- 用表格呈现总结/对比；表格的列/行结构由你根据内容自行设计，但必须贴合用户的具体需求（如按公司、按年度、按主题、按文档）。
- 内容简洁明了，要点尽量带数据；每个要点标注来源，格式：`[来源: 文档名, p页码, 章节]`。
- 只能基于检索结果总结，**禁止臆想或编造**；某主题检索不到内容时如实说明"未找到相关记录"。
- 用户有特殊规定（指定维度、篇幅、格式、输出文件路径等）时，优先按用户要求输出。
- 信息不足无法完整总结时，说明缺口并兜底回复，不要强行填充。

## 工具说明

- `kb_list_docs`：列出企业知识库文档（company_code / status 过滤），返回 `doc_id` 等元信息，用于确定总结/对比范围。
- `rag_search`：知识库检索（常驻工具），传 `doc_ids` 可限定范围，返回带来源的内容片段。
- `file_write`：写入本地文件（需审批），用于输出分析文档；`sandbox_exec` 可执行 `mkdir` 建目录。
