# Knovis 数据查询

查询 Knovis 社交平台的动态流、动态详情与用户资料。所有查询为**只读**操作，token 由系统安全解密（明文不落库不日志），你无需也无法获取 token。

## 可用操作（内置工具，加载后直接调用）

| 工具 | 用途 | 关键参数 |
|------|------|---------|
| `knovis_get_feed` | 动态流 | `page`（从 1 开始）、`page_size`（默认 10，最大 50） |
| `knovis_get_profile` | 用户资料 | `user_id`（空则查当前登录用户） |
| `knovis_get_post` | 动态详情 | `post_id`（必填，浏览数 +1） |

## 执行流程

1. 根据用户需求选择合适的工具（查动态流 / 查用户 / 查单条动态）。
2. 查询结果按用户问题组织回答，标注数据来源（如"来自动态流第 N 条"）。
3. 用户对某条动态感兴趣时，可继续用 `knovis_get_post` 查详情。

## 注意事项

- Knovis 不提供点赞/评论/关注/发帖等社交互动接口，相关写操作请在 Knovis 前端完成。
- 用户未设置 Knovis token 时，工具会返回明确错误，请如实告知用户先去设置。
