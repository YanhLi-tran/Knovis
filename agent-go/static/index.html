⬇ 前往下载页面
  1. 下载并解压对应你系统的 local-agent 文件
  2. 双击运行（Windows 为 .exe），保持窗口常开
  3. 回到本页面重新登录（或刷新），登录后会自动激活并绑定当前账号
  4. 部署在服务器时需指定：local-agent --server ws://服务器IP:8001（可选 --workdir 指定工作目录）
