### 1.2 🟡 P1:工程深度待加强

#### 1.2.1 Rerank 实际接入
- **现状**:✅ **已接入并评测(2026-08-05)** — [reranker.py](../doc-service/reranker.py) 支持 bge-reranker-v2-m3(CrossEncoder,FP16,max_length=512),`RERANK_ENABLED=true` + `RERANK_MODEL_PATH` 启用;Before/After 评测见 [03-评测体系建设.md §六](./03-评测体系建设.md)
- **现状结论**:评测显示 rerank 当前配置下 Recall@5 88.4%→78.5% 轻微下降(截断/chunk 粒度问题),默认 `RERANK_ENABLED=false` 保持关闭
- **待办(如需启用)**:
  - [ ] 增大 max_length 至 1024(当前 512 < chunk_size 800,截断丢关键信息)
  - [ ] 混合排序:`final_score = 0.5 * fusion + 0.5 * rerank`
  - [ ] 场景路由:multi_recall 等短 query 场景跳过 rerank

#### 1.2.2 Chroma HNSW 技术债
- **现状**:[store.py](../doc-service/store.py) 用 numpy 暴力 cosine 绕过 Chroma HNSW(18801 向量 73MB,<50ms,当前可扛)
- **风险**:
  - 扩到 10 万+ 向量会慢,无真正 ANN 索引
  - 简历写"Chroma"实际搜索路径绕过 HNSW,深挖露馅
- **待办(二选一)**:
  - [ ] 切换 Milvus Lite(简历更值钱 + 真 ANN 索引)
  - [ ] 简历明确写"自实现 brute-force cosine 替代有 bug 的 HNSW"(讲问题定位能力)
