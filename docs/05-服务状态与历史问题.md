## 二、当前服务状态

- **Go 主服务**:`http://127.0.0.1:8001`(API + OTACO 编排 + 记忆注入 + 自动提取)
- **Python 子服务**:`http://127.0.0.1:8002`(embedding + 混合检索 + 关键词提取,首次启动加载 bge-large-zh ~1.5GB)
- 数据库:MySQL `agent_go`(9 张表:sessions / messages / user_config / projects / memories / memory_archive / cross_project_grants / users / audit_logs)
- 缓存:Redis `127.0.0.1:6379`(不可用时自动降级直读 MySQL;缓存 user 档案 + 项目信息 + token 黑名单 + 限流计数;检索结果不缓存)
- 向量库:Chroma 嵌入式 `memory-service/data/chroma/`(按项目隔离 collection)
- 鉴权:JWT(HS256,access 2h + refresh 7d rotation)+ AES-256-GCM 凭证加密 + Redis 日计数限流
- 已注册工具:10 个常驻 FC(geocode_city / get_weather / get_weather_forecast / web_search / ask_user / file_read / file_write / grep / sandbox_exec / load_skill)+ 1 个 Skill(Knovis 9 工具,按需加载)
- WebSocket:/ws/agent(本地客户端连接,file/sandbox 工具下发指令通道)
- 环境变量:见 [.env.example](../agent-go/.env.example),需配置 `LLM_API_KEY`、`TENCENT_SECRET_ID/KEY`、`DB_*`、`REDIS_*`、`MEMORY_SERVICE_URL`、`JWT_SECRET`、`MASTER_KEY_V1`、`KNOVIS_API_BASE_URL`
